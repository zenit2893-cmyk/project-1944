# Project 1944 1.0 — встановлення

[English](INSTALL_EN.md) · [Русский](INSTALL_RU.md) · Українська

**Потрібна власна законно придбана копія Call of Duty 3 (USA, Europe) для Xbox 360.** Project 1944 не поширює та не завантажує гру. SHA-256 підтримуваного `default.xex`: `2944EEC7D1231AD6798B5F9F8ADF8855F5E489296B22EAB45B27A577CEE23692`.

## Перед початком

- Windows 10/11 x64 і відеокарта з підтримкою Direct3D 12.
- Близько 7 ГБ вільного місця для встановлення; близько 12 ГБ за повної компіляції.
- Власний ISO-диск Xbox 360, розпакована тека з `default.xex` або сумісний пакет Games on Demand у `415607E1\00007000`.

## Встановлення та запуск

1. Завантажте **`cod3-pc-full.zip`** і `SHA256SUMS.txt` з одного [релізу Project 1944](https://github.com/zenit2893-cmyk/project-1944/releases). Звірте SHA-256 архіву з файлом контрольних сум. Команда PowerShell: `Get-FileHash .\cod3-pc-full.zip -Algorithm SHA256`.
2. Повністю розпакуйте архів у нову теку на диску з достатнім вільним місцем. За можливості використовуйте шлях із латинських літер і цифр: гра може не відкрити шлях із нелатинськими символами, якщо Windows не створила для нього короткого імені 8.3.
3. Запустіть `Project1944.exe`. Резервний `launcher\PLAY-COD3.cmd` відкриває той самий лаунчер, якщо Windows блокує непідписаний EXE. Перш ніж змінювати налаштування безпеки Windows, прочитайте [пояснення щодо антивіруса](docs/antivirus.md).
4. Натисніть **«Обрати образ»** або перетягніть у вікно ISO, `default.xex`, теку з грою чи GOD-пакет.
5. Натисніть **«Встановити й грати»**. Лаунчер перевірить джерело, скопіює ігрові файли до локальної `game\cod3`, перевірить перекомпіляцію та запустить гру. Перерване встановлення можна продовжити.

Переклад коду на перевіреному ПК зазвичай триває близько хвилини; якщо результат збігається з готовою збіркою, компілятор не потрібен. Необов'язкова кнопка **«Перезібрати гру»** запускає повну компіляцію на 10–30 хвилин. Якщо Visual Studio C++ немає, цей крок завантажить MSVC та Windows SDK із серверів Microsoft. Перемикач **«Перекомпілювати гру на цьому комп'ютері»** можна вимкнути, щоб після перевірки джерела використати готову збірку.

## Якщо виникла проблема

Перевірено першу місію Saint-Lô; усю кампанію й інше обладнання поки не перевірено. Трава може відображатися витягнутими смугами; тимчасовий режим приховує стебла. Старі геймпади, що підтримують лише DirectInput, типово не виявляються. Подробиці — в [інструкції для тестувальників](docs/testers.md) і [таблиці керування](docs/controls.md).

Натисніть **«Звіт про помилку»** в лаунчері й опишіть місію, контрольну точку, кроки та результат. Перед надсиланням перевірте діагностичний ZIP на особисті дані. Ніколи не додавайте ISO, розпаковані ігрові файли або згенерований ігровий код.
