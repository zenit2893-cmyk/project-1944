# Support / Поддержка

For setup help and general discussion, start in the [Project 1944 Discord](https://discord.gg/7sGEwV3sB). For a reproducible bug, use the GitHub bug-report form and identify the port version, game source revision, mission, checkpoint, expected behavior, actual behavior, and steps to reproduce. The launcher's **Bug report** button can collect logs and system information. Review the ZIP before sharing it, and never attach game data.

За помощью с установкой и общими вопросами обращайтесь в [Discord Project 1944](https://discord.gg/7sGEwV3sB). Для воспроизводимой ошибки используйте шаблон GitHub: укажите версию порта, ревизию игровой копии, миссию, чекпоинт, ожидаемое и фактическое поведение, а также шаги повторения. Кнопка **«Отчёт об ошибке»** собирает логи и сведения о системе. Проверьте ZIP перед отправкой и никогда не прикладывайте игровые данные.

За допомогою зі встановленням і загальними питаннями звертайтеся до [Discord Project 1944](https://discord.gg/7sGEwV3sB). Для відтворюваної помилки використовуйте шаблон GitHub: укажіть версію порту, ревізію копії гри, місію, контрольну точку, очікувану й фактичну поведінку та кроки відтворення. Кнопка **«Звіт про помилку»** збирає журнали й відомості про систему. Перегляньте ZIP перед надсиланням і ніколи не додавайте ігрові дані.
