# Антивирусы, SmartScreen и Smart App Control

Честно с самого начала: гарантировать, что ни один антивирус никогда не ругнётся, нельзя. Пакет пересобирает игру — то есть скачивает компилятор и запускает только что собранные неподписанные программы. Ровно это и делает вредоносное ПО, и эвристики смотрят на поведение, а не на намерения. Но почти всю ругань можно убрать, и ниже — что для этого сделано и что можете сделать вы.

## Что уже сделано в пакете

- **В скриптах нет приёмов, на которые срабатывают эвристики.** Ни `Invoke-Expression`, ни `DownloadString`, ни base64-строк, ни `-EncodedCommand`, ни скрытых окон, ни самоповышения прав. Всё открытым текстом.
- **Каждая загрузка сверяется по SHA-256** с закреплённым значением в `tools/toolchain-provision/toolchain-pins.json`. Не совпало — файл удаляется, шаг падает.
- **Инструменты скачиваются у правообладателей**, а не лежат в архиве. Файл приходит с сайта LLVM, Kitware, Microsoft или автора xdvdfs со своей репутацией, а не как безымянный `.exe` из чужого архива.
- **Снимается «метка интернета»** с проверенных загрузок, иначе Windows предупреждает при первом запуске каждого инструмента.
- **Лаунчер запускается под `AllSigned`**, если пакет подписан, и только без подписи — под `Bypass`.
- В архиве нет ни одного постороннего исполняемого файла: только сама игра, библиотеки уровней и runtime SDK.

## Три способа убрать предупреждения

### 1. Подпись — единственное настоящее решение

Антивирус, SmartScreen и Smart App Control оценивают репутацию файла. У программы, собранной пять минут назад, её нет. Подпись это меняет.

```powershell
powershell -ExecutionPolicy Bypass -File tools\signing\Set-Cod3Signature.ps1 -CertificateThumbprint <отпечаток> -IncludeBinaries
```

| Сертификат | Что даёт |
|---|---|
| EV от публичного центра сертификации | Репутация сразу: ни SmartScreen, ни Smart App Control не возражают |
| Обычный от публичного ЦС | Репутация накапливается по мере расхождения подписанных копий |
| Самоподписанный | Работает только там, где ему доверяют: снимает «неизвестный издатель» и позволяет `AllSigned`. На SmartScreen и Smart App Control **не влияет** |

Самоподписанный делается так:

```powershell
powershell -ExecutionPolicy Bypass -File tools\signing\New-Cod3CodeSigningCertificate.ps1
```

Ключ `-TrustLocally` дополнительно внесёт его в доверенные корневые на вашей учётной записи. Это меняет то, что ваша машина считает подписанным кодом, поэтому по умолчанию он выключен: включайте только для сертификата, который создали сами.

### 2. Исключение в Defender — быстро, но это «не смотри сюда»

```powershell
# в PowerShell от имени администратора
powershell -ExecutionPolicy Bypass -File tools\signing\Set-DefenderExclusions.ps1
```

Исключение охватывает только каталог пакета и каталоги сборки, не весь диск и не процессы. Отменяется ключом `-Remove`. Заодно заметно ускоряет полную пересборку: реальное время сканирования десятков тысяч объектных файлов сопоставимо с временем компиляции.

Это ваша настройка безопасности — скрипт лежит в пакете, но ничего не вызывает его автоматически, и сам он прав не повышает.

### 3. Ничего не делать

Пересборка пройдёт и так, если Smart App Control выключен. Вы увидите несколько предупреждений SmartScreen при первом запуске инструментов.

## Smart App Control — отдельная история

Это **не антивирус**, а политика управления приложениями. Она отказывается запускать неподписанные программы без репутации и не имеет настройки «разрешить эту». Ни исключения Defender, ни самоподписанный сертификат её не обходят.

Проверить состояние:

```powershell
(Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy').VerifiedAndReputablePolicyState
```

`0` — выключен, `1` — включён, `2` — режим оценки. Лаунчер читает то же значение и предупреждает заранее.

Убедиться, что остановил сборку именно он, а не антивирус, можно по журналу (нужен PowerShell от администратора):

```powershell
Get-WinEvent -FilterHashtable @{ LogName='Microsoft-Windows-CodeIntegrity/Operational'; StartTime=(Get-Date).AddHours(-1) } |
  Select-Object TimeCreated, Id, Message -First 10
```

Событие **3118** «Smart App Control Block Details» рядом с ошибками **3033** и **3077** — это он. Если таких событий нет, а файл всё равно не запускается, ищите причину в антивирусе.

Если включён, вариантов два: подписать сборку сертификатом публичного ЦС либо выключить Smart App Control в «Безопасность Windows» → «Управление приложениями и браузером». **Выключение необратимо** — включить обратно можно только переустановкой Windows, поэтому решение принимаете вы, и пакет за вас его не принимает.

Блокировка бывает выборочной: один свежесобранный инструмент запускается, соседний — нет. Иногда снимается сама через некоторое время после первой попытки.

## Если файл всё-таки попал в карантин

1. Проверьте, что это именно наш файл: все хеши сборки записаны в `analysis/cod3-pc-native-build-receipt.json` и в `package-manifest.json`.
2. Отправьте образец на перепроверку — у Microsoft это [форма Submit a file](https://www.microsoft.com/en-us/wdsi/filesubmission). Ложные срабатывания на свежесобранных компиляторах правят обычно в течение суток.
3. Приложите файл к отчёту об ошибке: кнопка «Отчёт об ошибке» в лаунчере соберёт состав сборки и хеши. Игровых файлов в отчёте нет.
