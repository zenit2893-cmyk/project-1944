# Project 1944 1.0 — установка

[English](INSTALL_EN.md) · Русский · [Українська](INSTALL_UK.md)

**Нужна собственная легально приобретённая копия Call of Duty 3 (USA, Europe) для Xbox 360.** Project 1944 не раздаёт и не скачивает игру. SHA-256 поддерживаемого `default.xex`: `2944EEC7D1231AD6798B5F9F8ADF8855F5E489296B22EAB45B27A577CEE23692`.

## Перед началом

- Windows 10/11 x64 и видеокарта с поддержкой Direct3D 12.
- Около 7 ГБ свободного места для установки; около 12 ГБ при полной компиляции.
- Собственный ISO-диск Xbox 360, распакованная папка с `default.xex` или совместимый Games on Demand-пакет в `415607E1\00007000`.

## Установка и запуск

1. Скачайте **`cod3-pc-full.zip`** и `SHA256SUMS.txt` из одного [релиза Project 1944](https://github.com/zenit2893-cmyk/project-1944/releases). Сверьте SHA-256 архива с файлом контрольных сумм. Команда PowerShell: `Get-FileHash .\cod3-pc-full.zip -Algorithm SHA256`.
2. Распакуйте архив целиком в новую папку на диске с достаточным свободным местом. По возможности используйте путь из латинских букв и цифр: игра может не открыть путь с нелатинскими символами, если Windows не создала для него короткое имя 8.3.
3. Запустите `Project1944.exe`. Запасной `launcher\PLAY-COD3.cmd` открывает тот же лаунчер, если Windows блокирует неподписанный EXE. Прежде чем менять настройки безопасности Windows, прочитайте [пояснение об антивирусе](docs/antivirus.md).
4. Нажмите **«Выбрать образ»** либо перетащите в окно ISO, `default.xex`, папку с игрой или GOD-пакет.
5. Нажмите **«Установить и играть»**. Лаунчер проверит источник, скопирует игровые файлы в локальную `game\cod3`, проверит рекомпиляцию и запустит игру. Прерванную установку можно продолжить.

Перевод кода на проверенном ПК обычно занимает около минуты; если результат совпадает с готовой сборкой, компилятор не нужен. Необязательная кнопка **«Пересобрать игру»** запускает полную компиляцию на 10–30 минут. Если Visual Studio C++ нет, этот шаг скачает MSVC и Windows SDK с серверов Microsoft. Переключатель **«Рекомпилировать игру на этом компьютере»** можно выключить, чтобы после проверки источника использовать готовую сборку.

## Если возникла проблема

Проверена первая миссия Saint-Lô; вся кампания и другое оборудование пока не проверены. Трава может отображаться вытянутыми полосами; обходной режим скрывает стебли. Старые геймпады только с DirectInput по умолчанию не обнаруживаются. Подробности — в [инструкции для тестеров](docs/testers.md) и [таблице управления](docs/controls.md).

Нажмите **«Отчёт об ошибке»** в лаунчере и опишите миссию, чекпоинт, шаги и результат. Перед отправкой проверьте диагностический ZIP на личные сведения. Никогда не прикладывайте ISO, распакованные игровые файлы или сгенерированный игровой код.
